Project 1: Solar PV Power Output Prediction Using Machine Learning
This project focuses on building machine learning models to predict the power output of solar photovoltaic (PV) systems using historical data and weather conditions. Key tasks include data cleaning, seasonal feature extraction, exploratory data analysis, feature selection, and implementing XGBoost and Random Forest models. The models are optimized using hyper-parameter tuning and evaluated using various performance metrics.

Project 2: Research-Based Machine Learning Model Implementation
In this project, a research paper and its associated dataset were selected to implement a machine learning or ensemble learning model to solve the problem addressed in the study. The project involved preparing the dataset, selecting relevant features, applying suitable ML techniques, and analyzing the model’s performance. A 10-minute presentation was created to discuss the methodology and results.
